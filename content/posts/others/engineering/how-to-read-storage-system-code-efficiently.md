## 阅读方法论

首先看存储对象有几种，每一种是怎么定义的，尤其要看清楚原子对象的定义。描述这些对象的元数据、描述符，也一起看。

有了对象的定义，再顺着一个**单对象**的生命周期往下读。生命周期其实可以看成一个状态机，这里分开看状态本身、状态转移，以及触发和执行转移的手段。

**状态：** 先看对象存在哪种介质上，属于什么类型。再从原子对象的视角看，不同类型的存储对象之间做转换，对应着原子对象怎样的重排。最后看代码里如何确定或查验一个对象当前的状态。

**状态转移：** 主要看对象如何在不同介质之间流转。顺着这个过程，把伴随的元数据、描述符的流转，以及控制流怎么走，也一起理清楚。

**状态转移的手段：** 继续往下看一次跨介质传输具体怎么发生：什么条件会触发这次传输，触发后执行哪些操作，整个事务是同步还是异步。代码里又如何查验它已经发起、已经完成。

单对象看清楚以后，再扩展到**多对象**。多个存储对象的生命周期同时维护，状态机之间会出现哪些冲突，有哪些状态一致性协议，又有哪些并发抢占。

接着把视角放到**整个存储系统和外部的关系**上：外部流程走到什么阶段会调用它，它的上下层分别是什么。

这些关系理清楚了，最后再看**性能优化**。冷热路径各有哪些可能，怎么设计才能让热路径跑得更快，或者让 hot path 更多地走到 fast path 上。
